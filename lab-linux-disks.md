# Лабораторная работа. Работа с дисками в Linux

Дисциплина: администрирование информационных систем.

## Цель

Ознакомиться с командами для работы с дисками в Linux: смотреть список дисков, создавать и удалять раздел, создавать на нём файловую систему и монтировать её.

## Оборудование

Компьютер с Linux и права root. Используются `lsblk`, `fdisk`, `mkfs.ext4`, `mount` и `umount`.

Команды из методички для `/dev/sda` и `/dev/sda1` на рабочей системе выполнять нельзя. `/dev/sda` — это обычно системный диск. Запись таблицы разделов (`w` в `fdisk`) и `mkfs.ext4 /dev/sda1` уничтожают находящуюся там систему и данные. Ниже те же действия выполняются на файле-образе, который подключается как отдельный диск.

## Краткие сведения

`fdisk -l` показывает диски и разделы. Для этого нужны права root. Удобнее сначала смотреть краткий список:

```bash
lsblk -f
sudo fdisk -l
```

В колонке NAME видны имена вроде `sda`, `sdb`, `nvme0n1`. Раздел — это `sda1`, `nvme0n1p1`. Буквы и номера на конкретной машине могут быть другими. Перед любой записью сверяют имя по `lsblk`, а не подставляют `sda` из примера.

Форматирование и создание файловой системы в этой работе — одна и та же операция: `mkfs.ext4`. Отдельной второй команды нет.

В диалоге `fdisk` клавиша Enter не записывает таблицу. Запись и выход — команда `w`. Выход без записи — `q`. Размер `+100M` вводят в поле последнего сектора, а не вместо номера раздела.

## 1. Учебный диск

Образ на 200 МБ и подключение его как петлевого устройства:

```bash
mkdir -p ~/lab-disks && cd ~/lab-disks
truncate -s 200M disk.img
sudo losetup --find --show --partscan disk.img
```

Команда печатает имя, например `/dev/loop0`. Дальше вместо `LOOP` подставляют это имя. Это не системный диск.

```bash
lsblk "$LOOP"
```

## 2. Раздел 100 МБ

```bash
sudo fdisk "$LOOP"
```

В диалоге:

```text
n
p
1
<Enter>
+100M
w
```

По шагам: `n` — новый раздел, `p` — первичный, `1` — номер, Enter — первый сектор по умолчанию, `+100M` — размер, `w` — записать таблицу и выйти.

Если ядро не увидело раздел, таблицу перечитывают и проверяют:

```bash
sudo partprobe "$LOOP"
lsblk "$LOOP"
```

Появится раздел, например `/dev/loop0p1`. Дальше он назван `PART`.

## 3. Файловая система и монтирование

```bash
sudo mkfs.ext4 "$PART"
sudo mkdir -p /mnt/labdisk
sudo mount "$PART" /mnt/labdisk
df -h /mnt/labdisk
echo "disk lab" | sudo tee /mnt/labdisk/hello.txt
ls -l /mnt/labdisk
```

`mkfs.ext4` создаёт ext4 и стирает прежнее содержимое раздела. После `mount` файлы раздела видны в `/mnt/labdisk`.

Отмонтировать:

```bash
sudo umount /mnt/labdisk
```

Постоянная точка монтирования записывается в `/etc/fstab` по UUID из `blkid`, а не по имени `/dev/loop0p1`: номер петлевого устройства после перезагрузки меняется. Для учебного образа строку в `fstab` не добавляют.

## 4. Удаление раздела

Снова `fdisk` по тому же учебному диску:

```bash
sudo fdisk "$LOOP"
```

```text
d
1
w
```

`d` удаляет раздел, `1` выбирает первый, `w` записывает таблицу. Пока раздел смонтирован, его не удаляют: сначала `umount`.

Проверка:

```bash
lsblk "$LOOP"
```

## 5. Отключение образа

```bash
sudo losetup -d "$LOOP"
```

Файл `disk.img` можно оставить или удалить через `rm`. На системные диски это не влияет.

## Вывод

Список дисков дают `lsblk` и `fdisk -l`. Раздел создают и удаляют в `fdisk`: размер задаётся как `+100M` в последнем секторе, таблица записывается командой `w`. Файловую систему ext4 создаёт `mkfs.ext4`, подключает её `mount`, отключает `umount`. Эти команды применяют к заранее проверенному учебному диску. На системный `/dev/sda` их не направляют.
