# Лабораторная работа. Работа с файлами в Linux

Дисциплина: администрирование информационных систем.

## Цель

Ознакомиться с основными командами для работы с файлами в Linux. Научиться создавать, просматривать, копировать, перемещать, удалять файлы и каталоги и менять права доступа.

## Оборудование

Компьютер с Linux и терминал. Используются `touch`, `echo`, `cat`, `less`, `mkdir`, `cp`, `mv`, `rm`, `chmod` и `ls`.

Команды ниже рассчитаны на отдельный учебный каталог. Их не выполняют в домашнем каталоге поверх уже существующих файлов и тем более не выполняют от корня файловой системы.

```bash
mkdir -p ~/lab-files && cd ~/lab-files
```

## Краткие сведения

В методических указаниях две команды описаны неверно.

`mv` переносит и каталог, и файл без ключа `-r`. Такого ключа у `mv` нет: каталог перемещается как один объект. Рекурсия нужна `cp` и `rm`, потому что они обходят содержимое.

Права `chmod` задают тремя восьмеричными цифрами подряд, без двоеточий: владелец, группа, остальные. Каждая цифра — сумма трёх битов:

| Бит | Право | Буква |
| --- | --- | --- |
| 4 | чтение | r |
| 2 | запись | w |
| 1 | выполнение | x |

В указаниях чтение и выполнение переставлены местами. Цифра 1 — это выполнение, цифра 4 — чтение. Цифра 7 равна 4+2+1, то есть `rwx`. Запись `777` означает `rwxrwxrwx`: читать, писать и выполнять файл могут владелец, группа и все остальные. Для обычного файла такой режим шире, чем нужно. Типичный режим файла — `644` (`rw-r--r--`), каталога — `755` (`rwxr-xr-x`).

## 1. Создание файлов

Пустой файл:

```bash
touch myfile
ls -l myfile
```

`touch` создаёт файл, если его нет. Если файл уже есть, команда только обновляет время изменения.

Файл с текстом. Оператор `>` создаёт файл или затирает прежнее содержимое:

```bash
echo "Hello, world!" > myfile
```

Дописать строку, не стирая уже записанное, можно оператором `>>`:

```bash
echo "Second line" >> myfile
```

Каталог для следующих шагов создаёт `mkdir`. В указаниях он используется в `cp` и `mv`, но команда создания пропущена.

```bash
mkdir mydir
```

## 2. Просмотр файлов

Вывести файл целиком:

```bash
cat myfile
```

Постраничный просмотр удобен для длинного файла. `less` листает вперёд и назад, выход — клавиша `q`. `more` листает в основном вперёд.

```bash
less myfile
```

Имена и права, без содержимого, показывает `ls -l`.

## 3. Копирование

Копия файла под новым именем:

```bash
cp myfile myfile.copy
cat myfile.copy
```

Копия каталога вместе с содержимым. Сначала в каталог кладут файл, иначе копировать нечего:

```bash
echo "inside" > mydir/note.txt
cp -r mydir mydir.copy
find mydir.copy
```

Без `-r` команда `cp` отказывается копировать каталог.

## 4. Перемещение

Перенос файла в существующий каталог:

```bash
mv myfile.copy mydir
ls mydir
```

Переименование каталога. Ключ `-r` не нужен и в такой команде лишний: у `mv` его нет.

```bash
mv mydir.copy mydir.new
ls -ld mydir.new
```

После `mv` старого имени больше нет: это перенос, а не копия.

## 5. Удаление

Удаление файла:

```bash
rm mydir/myfile.copy
```

Удаление каталога и всего, что внутри. Каталог `mydir.new` создан на предыдущем шаге именно для этого:

```bash
rm -r mydir.new
ls
```

`rm` без `-r` каталог не удаляет. Ключ `-i` перед удалением спрашивает подтверждение по каждому имени. Эти команды относятся только к учебным `myfile` и `mydir` в каталоге `~/lab-files`.

## 6. Права доступа

Режим `777` из задания:

```bash
echo "Hello, world!" > myfile
chmod 777 myfile
ls -l myfile
```

В первой колонке `ls -l` будет `-rwxrwxrwx`. Первый символ `-` означает обычный файл, дальше три тройки: владелец, группа, остальные.

Более узкий режим, которым пользуются для обычных файлов:

```bash
chmod 644 myfile
ls -l myfile
```

Будет `-rw-r--r--`: владелец читает и пишет, группа и остальные только читают, выполнять файл нельзя.

Проверка битов по отдельности:

```bash
chmod 754 myfile
ls -l myfile
```

`754` раскладывается так: владелец 7 = `rwx`, группа 5 = 4+1 = `r-x`, остальные 4 = `r--`.

Тот же результат в буквенном виде:

```bash
chmod u=rwx,g=rx,o=r myfile
```

## Вывод

Пустой файл создаёт `touch`, файл с текстом — `echo` и перенаправление `>`. Содержимое смотрят через `cat` или `less`. Файл копирует `cp`, каталог — `cp -r`. Перенос и переименование делает `mv` без ключа `-r`. Файл удаляет `rm`, каталог с содержимым — `rm -r`. Права меняет `chmod`: три цифры отвечают владельцу, группе и остальным, а внутри цифры 4, 2 и 1 означают чтение, запись и выполнение.
