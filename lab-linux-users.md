# Лабораторная работа. Работа с пользователями в Linux

Дисциплина: администрирование информационных систем.

## Цель

Ознакомиться с основными командами для работы с пользователями в Linux. Научиться создавать, изменять и удалять учётные записи и назначать права через группы.

## Оборудование

Компьютер с Linux. Команды выполняет root или пользователь из группы `sudo`. Используются `useradd`, `chpasswd`, `usermod`, `userdel`, `id`, `getent` и `passwd`.

## Краткие сведения

В методических указаниях несколько команд описаны неверно. Ниже они заменены на штатные.

Ключ `-p` у `useradd` и `usermod` принимает уже посчитанный хеш пароля, а не текст `secret`. Если передать открытый текст, войти с паролем `secret` не получится. Пароль задают через `chpasswd` или `passwd`.

`userdel` без ключа `-r` удаляет учётную запись, но оставляет домашний каталог и файлы. Каталог удаляет только `userdel -r`.

Строка `user1:x:1000:1000:User1:/home/user1:/bin/bash:sudo` — это испорченная запись `passwd`, а не строка группы. В `/etc/group` её не дописывают. В группу `sudo` пользователя добавляет `usermod -aG`.

Поля `/etc/passwd`, семь штук:

1. имя;
2. признак пароля: `x` означает, что хеш лежит в `/etc/shadow`;
3. UID;
4. GID основной группы;
5. комментарий (GECOS);
6. домашний каталог;
7. оболочка входа.

Поля `/etc/group`, четыре штуки:

1. имя группы;
2. пароль группы или `x`;
3. GID;
4. дополнительные участники через запятую.

В указаниях у группы вторым полем назван GID, а третьим — список участников. На деле второе поле — пароль группы, третье — GID, список участников — четвёртое. Открытый пароль ни в `passwd`, ни в `group` не хранится.

В задании удаление стоит раньше изменения. После `userdel` менять эту учётную запись уже нельзя, поэтому ниже сначала создают пользователя, затем смотрят и меняют запись, и только в конце удаляют.

## 1. Создание пользователя

Домашний каталог и оболочка:

```bash
sudo useradd -m -d /home/user1 -s /bin/bash user1
```

Пароль `secret`:

```bash
echo 'user1:secret' | sudo chpasswd
```

Проверка:

```bash
getent passwd user1
id user1
ls -ld /home/user1
```

Строка имеет вид `user1:x:1000:1000::/home/user1:/bin/bash`. Числа UID и GID система выбирает сама; если 1000 свободен, будет он. Поле пароля содержит `x`.

## 2. Сведения о пользователях

Весь список учётных записей:

```bash
cat /etc/passwd
```

Одна запись, без посторонних строк:

```bash
getent passwd user1
```

Хеш пароля в этот список не входит. Его читает только root из `/etc/shadow`:

```bash
sudo getent shadow user1
```

Группы пользователя:

```bash
groups user1
getent group "$(id -g user1)"
```

## 3. Изменение пользователя

Новый пароль командой `usermod -p` не задают. Для смены пароля на `new_secret`:

```bash
echo 'user1:new_secret' | sudo chpasswd
```

Свой пароль пользователь меняет сам, команда спросит старый и новый:

```bash
passwd
```

`usermod` меняет параметры учётной записи. Другой домашний каталог. Ключ `-m` переносит уже созданные файлы:

```bash
sudo usermod -d /home/user1_home -m user1
getent passwd user1
```

Другая оболочка входа:

```bash
sudo usermod -s /bin/sh user1
```

Вернуть обычные значения:

```bash
sudo usermod -d /home/user1 -m -s /bin/bash user1
```

## 4. Права через группу

На Debian и Ubuntu право повышать привилегии даёт группа `sudo`. Ключ `-a` обязателен: без него `usermod` заменит список дополнительных групп.

```bash
sudo usermod -aG sudo user1
getent group sudo
groups user1
```

В строке группы последним полем появляется `user1`, например `sudo:x:27:user1`. На Fedora и RHEL та же роль у группы `wheel`. Имя группы проверяют так:

```bash
sudo grep -E '%sudo|%wheel' /etc/sudoers
```

Новое членство действует после повторного входа. Проверка:

```bash
su - user1
sudo whoami
exit
```

`sudo whoami` печатает `root`.

## 5. Удаление пользователя

Удалять учётную запись нужно не из её собственного сеанса. Ключ `-r` забирает и домашний каталог:

```bash
sudo userdel -r user1
getent passwd user1
ls -ld /home/user1
```

`getent` ничего не печатает. `ls` сообщает, что каталога нет. Без `-r` каталог `/home/user1` остался бы на диске.

## Вывод

Учётную запись создают командой `useradd` с ключами `-m`, `-d` и `-s`. Пароль задают и меняют через `chpasswd` или `passwd`, потому что ключ `-p` ждёт хеш. Параметры записи меняет `usermod`: домашний каталог, оболочку, дополнительные группы. Повышенные привилегии даёт включение в группу `sudo`, а не ручная строка в `/etc/group`. Список пользователей смотрят в `/etc/passwd`; хеши лежат в `/etc/shadow`. Вместе с домашним каталогом учётную запись удаляет `userdel -r`.
